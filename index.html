Inflação, juros, desemprego e dólar num só painel

Dashboard web feito com Python e Pandas, alimentado por dados abertos do Banco Central do Brasil. Sem chave de API, sem cadastro.

Quatro séries públicas, um conjunto de indicadores derivados

Os dados vêm do Sistema Gerenciador de Séries Temporais (SGS) do Banco Central. Cada série é alinhada em frequência mensal antes dos cálculos.

SérieCódigo SGSO que mede

O painel nunca fica em branco

Se a internet ou a API falharem, o app cai para a próxima fonte e avisa na tela qual está sendo usada.

  1. API do Banco CentralColeta em blocos de 5 anos e grava o resultado em data/cache.csv.
  2. Cache localSem conexão, mostra a última coleta bem-sucedida.
  3. Dados fictíciosSem cache, gera uma série de demonstração, sempre sinalizada com um aviso.

Rode em cinco minutos

Precisa de Python 3.10 ou superior. O painel abre no navegador, em localhost.

Instalação

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py

No Windows, ative o ambiente com .venv\Scripts\activate.

Estrutura do projeto

painel-macro/
├── app.py            interface (Streamlit + Plotly)
├── src/
│   ├── data.py       API, cache e fallback
│   └── indicators.py cálculos com Pandas
├── tests/            testes unitários
├── data/cache.csv    gerado na 1ª coleta
└── requirements.txt

Rode pytest para validar os cálculos.

Para evoluir o projeto

  • Incluir novas séries (PIB, IBC-Br, IGP-M): basta adicionar o código em SERIES.
  • Trazer dados regionais do IBGE (API SIDRA) e mostrar um mapa por estado.
  • Publicar de graça no Streamlit Community Cloud.
  • Destacar no gráfico quando o IPCA em 12 meses passar do teto da meta.
Dados: Banco Central do Brasil, portal de dados abertos (dadosabertos.bcb.gov.br). Projeto educacional, não constitui recomendação financeira.
